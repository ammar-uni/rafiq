## ماذا يضيف لسيرفرك؟

- **مساحة شخصية:** يفتح العضو `/rafiq` أو بطاقة الترحيب؛ خياراته تظهر له وحده.
- **كفارة المجلس باختيار العضو:** رسالة خاصة بعد مغادرة مجلس صوتي مشترك، مع مهلة للعودة ومنع التكرار.
- **مكتبة موثّقة:** خمسة أذكار وأدعية، بأزرار للتنقل وحفظ خاص. ترجع من المصدر إلى موضعك في المحفوظات.
- **فكرة تناسب موقفك:** ست أفكار يمكنك تصفّحها ضمن «مع أهلي» و«مع أصحابي» و«أثناء اللعب». لكل فكرة حديثها ورابطه وراويه في «الدليل والتوضيح»، مع تمييز الاقتراح العملي.
- **محفوظاتك في مكان واحد:** احفظ ذكرًا أو فكرة وارجع إليها من «محفوظاتي»، مع بقاء رابط المصدر وسياق التصفح. لا نسجّل هل عملت بالفكرة.
- **معاينة قبل التفعيل:** شاهد رسالة المجلس وافهم وقت وصولها قبل اختيار الاشتراك؛ التصفح وحده لا ينشئ اشتراكًا ولا يرسل رسالة.
- **مؤقّت استراحة:** رسالة واحدة بعد ١٥ أو ٣٠ أو ٦٠ أو ٩٠ دقيقة، مع تمديد ١٥ دقيقة حتى ساعتين من الآن. يمكنك طلب تذكير جديد من رسالة الاستراحة. لا يتكرر تلقائيًا.
- **تحكّم واضح:** صمت الإشعارات، وإيقاف مؤقت، وإلغاء تذكير سيرفر واحد أو الجميع، وحذف البيانات. لا منشن جماعي ولا نقاط للعبادة.

## منهج المحتوى

القرآن والسنة الثابتة، مع العناية بفهم السلف وشروح أهل العلم الموثوقين. المحتوى ثابت في `src/content.mjs` وله مصادر، منها الموقع الرسمي للشيخ ابن باز. لا يولّد البوت أحاديث أو فتاوى، ولا يخصّص ذكرًا بعدد أو وقت تعبدي من عنده.

كفارة المجلس مشروعة عند القيام من المجلس؛ مهلة إشعار التطبيق وسقف الرسائل تدابير لتقليل الإزعاج، وليست أوقاتًا أو أعدادًا شرعية. [تفاصيل المنهج والتوثيق](docs/content-policy.md).

طوبقت النصوص والعزو مع المراجع المباشرة، وسُجلت النتائج في [سجل مطابقة المحتوى](docs/content-audit.md). يمنع فحص التشغيل تمرير تغيير في مادة دينية لم يُحدّث سجل مراجعتها. هذه حماية من التغييرات العرضية، وليست تصحيحًا آليًا للحديث أو بديلًا عن المراجعة العلمية.

## تشغيله

تحتاج **Node.js 24 أو أحدث**، وتطبيق بوت من [بوابة مطوّري ديسكورد](https://discord.com/developers/applications).

```powershell
npm ci
npm run setup:local
```

املأ `DISCORD_APPLICATION_ID` و`DISCORD_TOKEN` في `.env` على جهاز التشغيل. يمكن وضع `DISCORD_GUILD_ID` لسيرفر تجربة؛ اتركه فارغًا لتسجيل الأوامر عالميًا. ينشئ أمر الإعداد مفتاح `RAFIQ_DATA_KEY` محليًا. انشر سياسة الخصوصية ووسيلة الدعم وضع رابطَيهما في `RAFIQ_PRIVACY_URL` و`RAFIQ_SUPPORT_URL` قبل التشغيل. ملف الأسرار والبيانات مستبعدان من Git.

```powershell
npm run doctor
npm run check
npm run invite
```

افتح رابط الدعوة الناتج وأضف البوت للسيرفر، **ثم** نفّذ:

```powershell
npm run register
npm start
```

يشغّل `npm start` مشرفًا يتابع اتصال البوت ونبضه ويعيد العامل المتعطل بفواصل متزايدة. افحص حالته عبر `npm run health` من نافذة أخرى. يحتاج المشرف نفسه إلى جهاز متصل أو خدمة استضافة؛ لا يعالج إطفاء الجهاز. راجع [الترقية من 0.4 والتشغيل المستمر](docs/setup.md#حفظ-البيانات-والتشغيل-المستمر) قبل تحديث نسخة قائمة.

استخدم `/rafiq-setup channel:...` بصلاحية إدارة السيرفر لنشر بطاقة الترحيب. لا يحتاج البوت صلاحية Administrator ولا أي Privileged Gateway Intent.

**الاتصال الفعلي يحتاج بيانات تطبيقك.** المحاكاة والاختبارات لا تتصل بديسكورد. [دليل الإعداد والتجربة](docs/setup.md).

## قواعد التذكير

| الحالة | سلوك رفيق |
| --- | --- |
| التفعيل | اختياري في كل سيرفر؛ التفضيلات وحدّ الرسائل مشتركان بين سيرفرات العضو |
| المجلس | قناة صوتية عادية، ٥ دقائق على الأقل، مع وجود شخص آخر في المجلس؛ لا تُحسب حسابات البوت |
| الخروج | انتظار نحو ٤٥ ثانية؛ انتقال القنوات والعودة السريعة لا ينتجان رسالة وداع |
| البداية | رسالة صامتة واحدة كل ٢٤ ساعة كحد أقصى |
| خيار «بعد المجالس» | فاصل ساعتين على الأقل، وحتى ٣ محاولات خلال ٢٤ ساعة عبر جميع السيرفرات |
| إيقاف ٢٤ ساعة | يوقف التنبيهات ويلغي المؤقّت؛ ثم تصبح المجالس التالية مؤهلة كالمعتاد |
| الخاص مغلق | تتوقف محاولات الوصول حتى ينجح اختبار الخاص الذي يطلبه العضو |
| إعادة التشغيل | تبقى التفضيلات والمحفوظات والمؤقّت؛ لا يُرسل وداع عن جلسة سابقة للتشغيل |
| تأخر المؤقّت | يُتجاوز إذا فات موعده بأكثر من ٥ دقائق؛ لا دفعة تذكيرات متراكمة |

الخاص بلا تنبيه يعني استخدام خيار ديسكورد لكتم إشعارات الدفع وسطح المكتب؛ يبقى ظهور الرسالة وحالتها غير المقروءة تابعين لديسكورد. التذكير إجراء مساعد ولا يضمن معرفة وقت انتهاء كل مجلس.

## تطوير وتجربة دون حساب بوت

```powershell
npm run check
npm run demo
npm run export:messages
npm run preview:build
npm run preview
```

`demo` يشغّل سيناريو تفعيل ومجلس ومؤقّت وحذف بيانات، في الذاكرة، دون شبكة. `preview:build` ينتج جزء HTML في `output/rafiq-identity.html` للعرض التفاعلي داخل المحادثة، و`preview` يعرضه في المتصفح على `http://127.0.0.1:43189` للتجربة المحلية. أمثلة JSON في `examples/` هي قوالب REST؛ يتولى `src/discord-adapter.mjs` تحويلها إلى خيارات discord.js وإرفاق الصور.

تعمل فحوص المحتوى والرسائل والسلوك تلقائيًا على GitHub. فحص بنية المراجع لا يقوم مقام التثبّت العلمي من الحديث.

عند تفعيل خدمة التحديث الموضّحة في [دليل VPS](docs/vps-deployment.md)، يفحص الخادم فرع `main` كل نحو خمس دقائق وينشر النسخة بعد نجاح الفحوص. تبقى الأسرار وتفضيلات المستخدمين منفصلة عن الكود؛ تغييرات تخزين البيانات غير المتوافقة تحتاج مراجعة يدوية.

## بنية المشروع

| المسار | الغرض |
| --- | --- |
| `src/content.mjs` | الأذكار والأفكار ومراجعها |
| `src/messages.mjs` | رسائل ومكوّنات ديسكورد الأصلية |
| `src/app.mjs` | تفاعلات العضو والتفضيلات |
| `src/reminders.mjs` | المجالس والمهلة وحدود الإرسال والمؤقّت |
| `src/store.mjs` و`src/encrypted-snapshot.mjs` | معاملات في الذاكرة وحفظ مشفّر |
| `src/index.mjs` | ربط أحداث ديسكورد وتشغيل البوت |
| `src/supervisor.mjs` و`scripts/healthcheck.mjs` | إعادة التشغيل ومراقبة الاتصال |
| `Dockerfile` و`compose.yaml` | حزمة لمضيف Docker قائم مع قرص بيانات دائم |
| `design/` و`assets/` | المعاينة والهوية والصور الأصلية |

شغّل عملية واحدة للبوت مع مجلد `data/` دائم. [التصميم التقني وحدود النسخة](docs/architecture.md).
