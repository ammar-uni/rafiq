# أصول رفيق

يُستخدم الغلاف في رسالة الترحيب المثبتة. تستخدم الأيقونة لصورة حساب البوت.
تبقى رسالة كفارة المجلس اليومية نصًا مقروءًا مع أزرار أصلية، دون إعادة تحميل الغلاف.

- `rafiq-banner-v2.webp`: الغلاف الحالي «خيرٌ يرافقك»، 1536 × 512، نحو 58 كيلوبايت.
- `rafiq-banner-v2-source.png`: الأصل الجديد المولد بأداة ImageGen.
- `rafiq-banner.webp`: الغلاف السابق المحفوظ للرجوع إليه.
- `rafiq-avatar.png`: أيقونة الحساب، مناسبة للاقتصاص الدائري.
- `rafiq-avatar.webp`: نسخة خفيفة للمعاينة.
- `rafiq-banner-source.png` و`rafiq-avatar-source.png`: النسختان الأصليتان المولدتان.

التوليد بأداة ImageGen المدمجة. تفاصيل الاتجاه الفني والنصوص في `design/brand.md`.
