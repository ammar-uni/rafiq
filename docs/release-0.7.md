# رفيق 0.7 — مواقيت الصلاة باختيارك

يختار المستخدم مدينته ويبدأ بطريقة أم القرى — مكة افتراضيًا، مع حساب العصر عند الظل مثله. يراجع الجدول قبل التفعيل، ويمكن ضبط الحساب من الإعدادات. يصل تذكير خاص للصلوات الخمس، مستقل عن تذكير المجلس، مع عرض الصلاة القادمة وتعديلات الدقائق وخيار رسالة صامتة أو إشعار ديسكورد المعتاد. زر الاختبار يرسل تجربة واضحة دون الادعاء بدخول وقت الصلاة.

المدينة اختيار يدوي، دون طلب موقع الجهاز أو عنوان المنزل. يُرسل نص البحث فقط إلى Open-Meteo / GeoNames، ثم يُحسب الجدول محليًا باستخدام Adhan JS. تُحفظ إعدادات الصلاة ومحاولات الإرسال مشفّرة، ويمكن إيقافها أو حذفها. تغيير الحساب أو المدينة يتطلب مراجعة الجدول وإعادة التفعيل.

أضيف كتالوج أصوات فارغ قابل للتعبئة لاحقًا؛ لا يُرفق ملف إلا لمن اختاره. الملفات تُشغّل يدويًا. التشغيل التلقائي لصوت خاص أثناء اللعب لم يُنفّذ؛ يحتاج تطبيقًا مرافقًا، ولا نوسّع صلاحيات القنوات الصوتية لهذا الغرض.

## التحقق

- 78 اختبارًا و119 نموذج رسالة، بما في ذلك مناطق زمنية مختلفة والتوقيت الصيفي وخط التاريخ الدولي وحجب الجداول القطبية غير الصالحة. حساب العصر ثابت دون قائمة بدائل، وتُعالج الإعدادات القديمة مع طلب مراجعة الجدول قبل إعادة تفعيل التذكير.
- مقارنة حالة مكة 2016-01-05 بالمرجع المنشور في اختبارات Adhan؛ هذا فحص تكامل محدد، وليس ضمان تطابق كل مدينة مع كل تقويم محلي.
- منع التكرار بعد إعادة التشغيل أو تعديل المواقيت، وإهمال المواعيد القديمة، واحترام الإيقاف والخاص المغلق وحذف البيانات.
- قراءة بيانات v1 وحفظ اختيارات الصلاة في v2، مع اختبار التشفير واسترجاع الحالة عند فشل الكتابة.
- فحص مدخل بحث المدن الفعلي باستخدام مدينة برلين العامة، دون بيانات مستخدم أو ديسكورد. اختبارات المعاينة تستخدم مدنًا تجريبية ولا تتصل بالبحث.
- الأذكار والأحاديث ومراجعات مصادرها لم تتغير.

التحديث محلي ولم يُنشر إلى GitHub أو ديسكورد أو الخادم. اختبار حاوية Docker موجود في CI، ولم يُشغّل هنا لعدم توفر Docker. تعليمات النشر والترقية والصوت في [دليل مواقيت الصلاة](prayer-reminders.md).
