# رفيق 0.13.6 — بداية أوضح وتطبيق ويندوز

اعتمد صاحب المشروع معاينة الإطلاق بتاريخ ٣١ أكتوبر ٢٠٢٦، مع إبراز مواقيت الصلاة في شريط المهام. يُوثّق إتمام النشر في تقرير التنفيذ.

يكتب المشرف `/rafiq-setup` داخل قناة مثل «رفيق الخير» لإظهار بطاقة البداية فيها مباشرة؛ يبقى خيار القناة اختياريًا للتوافق مع الاستخدام السابق. تضم البطاقة «إعداد سيرفرك»، ويفتحه المشرف في ثلاث خطوات خاصة: قناة التذكيرات، المحتوى والمواعيد والمنشن، ثم المراجعة والتفعيل.

يشرح الدليل قناتين مقترحتين: «رفيق الخير» للبطاقة و«تذكيرات» للمنشورات. الأسماء أمثلة فقط، ويمكن استخدام قنوات موجودة. يبدأ السيرفر الجديد دون افتراض أن قناة البطاقة هي قناة النشر. تبقى قناة النشر المحفوظة في السيرفرات السابقة، وكل المواعيد والتفضيلات كما هي حتى يختار المشرف حفظ تعديل.

تسجيل الأوامر العالمي يحدّث وصف التطبيق بتعليمات البداية المختصرة فقط، بعد التحقق من هوية التطبيق. تسجيل سيرفر التجربة لا يغير الوصف العام. لا تغيير في صلاحيات التثبيت أو مخطط البيانات ٨ أو مكتبة الأحاديث الـ٣٦٠ أو تذكيرات الأعضاء.

[الدليل المصوّر](server-setup.md) · [التفاصيل](server-posts.md).

تضم البطاقة قسم «✨ جديد · رفيق على جهازك»، ورابط التنزيل الرسمي من Microsoft Store للمنتج `9NN8WLLF8P7Z`، ورابطًا ثابتًا إلى `https://rafiq.ammarbalkhi.com/#windows`. جُهّز أيضًا [منشور إطلاق مستقل بصورة فعلية للتطبيق](app-launch.md)، وهو خارج دورة التذكيرات. هذه معاينة قبل الإرسال؛ لا يُرسل إعلان أو منشن تلقائي بمجرد نشر البرنامج. نسخة Windows 11 x64 متاحة عبر المتجر، ونسختا macOS وLinux قيد التطوير.
