# رفيق — الإصدار 0.13.3

أُضيفت عشرون رسالة موثقة من صحيح البخاري وصحيح مسلم، بأرقام ثابتة ٢١–٤٠، ليصبح مجموع المنشورات العامة أربعين. لكل منشور نص معتمد وراوٍ ورابط المصدر وتوضيح حدود النقل؛ تظهر التفاصيل من زر «المصدر والتوضيح». [ملف مراجعة الدفعة](reminder-posts-21-40.md).

تدخل المنشورات الجديدة في التناوب عند المواعيد المحفوظة. لا تزيد الترقية عدد الرسائل ولا تفعل النشر لسيرفر متوقف. النصوص العشرون السابقة والأذكار والمواسم وإعدادات المستخدمين والسيرفرات كما هي. لا تغيير لمخطط التخزين ٨، ولا ترحيل للتفضيلات أو تعديل للمنشن.

الفحوص المطلوبة قبل النشر: `npm ci --ignore-scripts`، ثم `npm run check` لمطابقة النصوص والبصمات وواجهات ديسكورد واختبارات التناوب وحفظ الإعدادات. تتبعها فحوص Linux والحاوية في GitHub، ثم التحقق من تشغيل البوت على الخادم دون إرسال رسائل تجريبية أو قراءة محادثات.
