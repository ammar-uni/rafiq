# شروط استخدام رفيق

آخر تحديث: ٨ سبتمبر ٢٠٢٦.

يدير رفيق مشغّل المشروع، ويمكن التواصل معه عبر [مساحة دعم رفيق في ديسكورد](https://discord.gg/x2q3gWM2Q).

استخدم رفيق للذكر وعمل الخير وتنظيم الوقت باختيارك، مع احترام الآخرين و[إرشادات مجتمع ديسكورد](https://discord.com/guidelines) و[شروط ديسكورد](https://discord.com/terms). لا تستخدم الخدمة للإزعاج أو المضايقة أو التحايل على الحظر وحدود المنصة.

الخدمة موجّهة لمن يستوفون الحد الأدنى لاستخدام ديسكورد في بلدهم: ١٣ سنة على الأقل، وقد يكون أعلى. لا نطلب تاريخ ميلاد أو وثائق هوية.

تفعيل تذكير المجلس اختياري في كل سيرفر، ومؤقّت الاستراحة رسالة تختار موعدها. يمكنك إلغاء التنبيهات وحذف بياناتك من داخل البوت. تشرح [سياسة الخصوصية](privacy-policy.md) البيانات المستخدمة وكيفية التحكم فيها.

نعتني بالقرآن والسنة الثابتة وشروح أهل العلم. تُعرض مصادر المحتوى، وتُميّز الاقتراحات العملية عن النصوص الشرعية. البوت لا يولّد فتاوى ولا يُعد بديلًا عن سؤال أهل العلم. قد يتأخر التذكير أو يتوقف بسبب الاتصال؛ يمكنك إلغاؤه متى شئت.

للإبلاغ عن خلل، أو محتوى يحتاج مراجعة، أو مشكلة خصوصية، تواصل مع المشغّل عبر مساحة الدعم. لا ترسل كلمات مرور أو رموز دخول أو بيانات خاصة عن غيرك، ولا تنشر معلومات حساسة في قناة عامة.

نحدّث هذه الوثائق عند تغيير معالجة البيانات أو الاستضافة أو وسيلة الدعم، ونوضّح التغييرات الجوهرية قبل بدء المعالجة الجديدة. النسخة الحالية مؤرخة أعلى كل وثيقة.
