# مواقيت الصلاة في رفيق 0.7

## للمستخدم

افتح `/rafiq` ثم «مواقيت الصلاة»: اختر مدينتك ليظهر جدولها. طريقة الحساب الافتراضية **أم القرى — مكة**، والعصر على حساب الظل مثله بعد استثناء ظل الزوال. تُحسب المواقيت لإحداثيات مدينتك ومنطقتها الزمنية، ولا تُنسخ إليها ساعات مكة. راجع المواقيت، وبعدها اضغط «راجعت الجدول؛ فعّل التذكير». لا يتفعّل بمجرد التصفّح أو البحث. يصل تذكير خاص لكل صلاة من الصلوات الخمس، حتى لو كنت في محادثة صوتية؛ لا يعتمد على مغادرتها.

طريقة الإشعار مستقلة عن تذكير المجلس: رسالة صامتة افتراضيًا، أو إشعار ديسكورد المعتاد باختيارك. يمكنك اختبار الإشعار قبل التفعيل. كتم التطبيق وإعدادات الإشعارات وعدم الإزعاج قد تمنع ظهوره أو سماعه. لا يضمن البوت تشغيل صوت أثناء الألعاب.

تغيير المدينة أو طريقة الحساب أو تعديلات الدقائق يوقف تذكير الصلاة حتى تراجع الجدول الجديد وتعيد تفعيله. حدّث المدينة يدويًا عند السفر. الإيقاف العام والحذف يشملان الصلاة؛ إلغاء اشتراك مجلس في سيرفر واحد لا يغيّرها.

## الحساب وحدوده

- الحساب محلي باستخدام [Adhan JS 4.4.6](https://github.com/batoulapps/adhan-js)، وليس نموذج ذكاء اصطناعي. لا تُضاف آيات أو أحاديث جديدة في هذه الميزة.
- تُستخدم إحداثيات مركز المدينة، والمنطقة الزمنية IANA مع التوقيت الصيفي. يفصل الحساب بين تاريخ المدينة والمنطقة الزمنية لخادم البوت، ويعالج خط التاريخ الدولي.
- يبدأ المستخدم الجديد بطريقة أم القرى، وحساب العصر ثابت عند بلوغ الظل مثله بعد استثناء ظل الزوال، دون قائمة للتبديل بين طريقتين؛ وهو الوصف المذكور في [شرح ابن باز لبداية أوقات الصلاة](https://binbaz.org.sa/fatwas/15630/بداية-ونهاية-اوقات-الصلاة). يظهر اسم طريقة الحساب قبل التفعيل، وتبقى إعدادات حساب الفجر والعشاء لمطابقة الجداول المحلية. راجع [توثيق المعاملات](https://github.com/batoulapps/adhan-js/blob/develop/METHODS.md).
- تعديل مستقل من ‎-60 إلى ‎+60 دقيقة لكل صلاة، بالإضافة إلى معاملات الطريقة الأصلية. تقارن المواقيت بجدول الجهة المعتمدة محليًا، ولا تُستخدم هذه المرونة لاختراع مواقيت.
- أم القرى: فاصل العشاء ٩٠ دقيقة أو ١٢٠ باختيار المستخدم. اختيار رمضان **يدوي**، ولا يستنتج البوت بداية الشهر أو نهايته. يُعاد الاختيار بعد رمضان حسب الجدول المحلي.
- يُعرض تقدير الليل المختار بوضوح. لا يُستبدل الليل أو النهار القطبي المتصل بمواقيت منطقة أخرى تلقائيًا؛ يُحجب الجدول غير الصالح ولا يُرسل عنه تذكير.
- التحقق كل ٥ ثوانٍ تقريبًا أثناء الاتصال؛ الشبكة وحدود ديسكورد قد تؤخر التسليم. تُترك المواعيد الفائتة بأكثر من دقيقتين، ولا ترسل دفعة تعويض بعد التوقف.
- حجز الإرسال يُحفظ مشفّرًا **قبل** طلب ديسكورد. الخطأ الشبكي الملتبس قد يفوّت تذكيرًا، لكنه لا يطلق إعادة محاولات مزعجة. لا تتكرر الصلاة لنفس المستخدم واليوم، مع فاصل ١٢ ساعة لنفس الصلاة عند تبديل المناطق.

## البحث والخصوصية

البحث الاختياري يستخدم [Open-Meteo / GeoNames](https://open-meteo.com/en/docs/geocoding-api). يُرسل اسم المدينة المكتوب فقط ومعاملات البحث، دون معرّف ديسكورد. الاختيار المحفوظ مشفّر مع باقي البيانات. توجد حدود بحث: ١٥ ثانية بين محاولات المستخدم، و٣٠ بحثًا بالدقيقة و٢٥٠٠ خلال ٢٤ ساعة للنسخة المشغّلة. عدّادات البحث مؤقتة في الذاكرة. الحساب اليومي لا يحتاج هذه الخدمة بعد اختيار المدينة.

خدمة البحث المجانية مخصصة للاستخدام غير التجاري بحسب [شروط Open-Meteo](https://open-meteo.com/en/terms). راجع المزود أو استبدل `lookup` عند تحويل المشروع إلى خدمة تجارية، أو توسع يستدعي موارد إضافية. لا توجد خطة مدفوعة أو حساب استضافة جديد ضمن هذا التحديث.

## إضافة أصوات لاحقًا

الأساس جاهز لملفات **يشغّلها المستخدم يدويًا**. الكتالوج فارغ افتراضيًا، ولا يوجد إذن للانضمام إلى القنوات أو التحدث فيها.

1. ضع تسجيلًا تملكه أو تملك إذن استخدامه في `assets/sounds/` بصيغة MP3 أو OGG أو WAV، بحجم لا يتجاوز 1 MiB. اختر ملفًا قصيرًا، وراجع النص والنسبة إن تضمّن محتوى دينيًا.
2. أضف مدخلًا إلى `assets/sounds/catalog.json`، مثل:

```json
[
  { "id": "gentle", "label": "تنبيه هادئ", "filename": "gentle.mp3" }
]
```

3. شغّل `npm run check` للتحقق من الكتالوج، ثم أعد نشر وتشغيل النسخة حين يكون النشر مطلوبًا. يظهر الملف تلقائيًا في قائمة «الإشعار والصوت»؛ لا يُرفق إلا لمن اختاره. حذف مدخل يعيد التسليم إلى رسالة دون ملف.

تُرفض المسارات الخارجية والروابط الرمزية والامتدادات غير المدعومة والملفات الكبيرة أو غير المتوافقة مع ترويسة صيغتها. يشمل بناء Docker الكتالوج والصيغ المسموح بها. اختبار الترويسة لا يغني عن مراجعة التسجيل والاستماع إليه قبل النشر.

ديسكورد لا يتيح عبر رسالة البوت تشغيل صوت مخصص تلقائيًا على جهاز شخص واحد. [Soundboard](https://docs.discord.com/developers/resources/soundboard) يسمعه المشاركون في القناة. التشغيل الشخصي التلقائي أثناء اللعب يحتاج مستقبلًا تطبيقًا مرافقًا يثبّته المستخدم ويمنحه الإذن؛ لا ندّعي توفره حاليًا.

## التشغيل والترقية

هذا التحديث جاهز محليًا ولم يُشغّل على الخادم. عند استئناف إعداد الخادم: انشر النسخة وحدّث الأوامر عبر `npm run register`، ثم اختبر رسائل مدينة وطريقة معروفتين بحساب تجريبي موافق. لا يلزم توسيع صلاحيات البوت أو إضافة intent جديد.

صيغة البيانات الجديدة v2 تقرأ بيانات v1 وتحفظها بصيغة v2 عند أول تعديل، دون إرسال أو تفعيل اشتراكات جديدة. احتفظ بنسخة مشفّرة قبل الترقية؛ النسخة القديمة لا تقرأ v2، فلا تُشغّلها فوق البيانات الجديدة. لا تبدأ عمليتين على مخزن واحد.

إذا وُجد اختيار قديم لحساب العصر المتأخر، يُحوّل عند القراءة إلى الحساب الثابت، ويُوقف تذكير الصلاة حتى يراجع المستخدم الجدول ويعيد تفعيله. تبقى المدينة والمحفوظات وسائر الإعدادات محفوظة.
