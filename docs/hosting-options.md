# خيارات استضافة رفيق

تاريخ التحقق: ٨ سبتمبر ٢٠٢٦. لم يتم إنشاء حساب استضافة أو إدخال بطاقة دفع أو نقل رمز البوت أو بياناته إلى أي من الخدمات التالية.

## النتيجة

لم نجد في الخدمات التي راجعناها خيارًا موثوقًا يحقق معًا: تشغيلًا مستمرًا، وصفر تكلفة، وعدم مشاركة أي بيانات حساب أو اتصال. إنشاء حساب باسم مشروع قد يخفي الاسم الحقيقي عن الجمهور، لكنه لا يمنع مزوّد الاستضافة من معالجة بيانات الحساب وعنوان الاتصال. لا تعني «مجاني» استمرارية مضمونة.

## أقرب الطرق العملية

مع رفض الدفع ومشاركة بيانات حساب جديدة، أقرب مسار هو جهاز دائم التشغيل تملكه بالفعل، أو استضافة يمنحها شخص موثوق بموافقته. لا يعمل البوت من جهاز مطفأ، ولا يتحول مستودع GitHub إلى خادم بمجرد رفع الكود.

إذا أصبح قبول حساب مشروع مستعار ممكنًا، يمكن تقييم Discloud كتجربة صغيرة بعد مراجعة بيانات تسجيل الدخول، ودعم Node.js 24، وحفظ الملفات واستهلاك الذاكرة فعليًا. موافقة استخدام الحساب أو رفع رمز البوت ليست ضمن هذا المستند.

إذا أُتيح الدفع مستقبلًا، تسهّل خدمة تدعم العمليات المستمرة وقرصًا دائمًا التشغيل. [Railway Hobby](https://docs.railway.com/pricing) يبدأ من ٥ دولارات شهريًا تشمل رصيد استخدام؛ الاستخدام الأعلى يزيد الفاتورة. لا نختار هذه الخطة دون موافقة على التكلفة. تحديث سياسة الخصوصية باسم المزوّد وآلية المعالجة مطلوب قبل نقل بيانات المستخدمين إليه.

## جاهزية البرنامج للنقل

- Node.js 24 أو أحدث، عملية واحدة ومجلد بيانات دائم على قرص محلي؛ لا تشغيل موزّع أو مجلد شبكة.
- `npm start` يشغّل مشرفًا يعيد العامل المتعطل بفواصل متزايدة، ويتحقق من نبضه واتصاله. الأخطاء الحرجة في الإعدادات أو المحتوى أو التخزين توقف المحاولات للمراجعة.
- ملف `.guard` فارغ يستخدم قفل نظام التشغيل، فيتحرر القفل عند موت العملية دون حذف البيانات. يجب عدم حذف الملف نفسه أثناء التشغيل.
- `npm run health` يفحص نبض العامل وحالة اتصال البوابة. لا يحاكي ضغط عضو على زر ولا يثبت إمكانية إرسال رسالة خاصة لكل عضو.
- `Dockerfile` يحزم ملفات التشغيل فقط، ويعمل بمستخدم غير إداري؛ تُحقن الأسرار عند التشغيل، ولا تدخل `.env` أو بيانات المستخدمين في الصورة.
- `compose.yaml` مثال لمضيف Docker قائم: قرص بيانات دائم، وإعادة تشغيل خارجية محدودة بخمس محاولات. يحتاج المضيف نفسه مراقبة وإعداد تشغيل عند الإقلاع إن أريد ذلك. حالة Docker `unhealthy` وحدها لا تعيد تشغيل الحاوية.
- قبل النقل: أوقف النسخة المحلية، وانقل اللقطة المشفّرة ومفتاحها عبر قناتين مناسبتين، وتحقق من البيانات والاتصال. لا تشغّل نسختين بالرمز نفسه. لا تنقل ملف القفل القديم من 0.4.

لم يُنفّذ نقل خارجي حتى الآن، ولا تعني ملفات التجهيز أن الاستضافة بدأت.
