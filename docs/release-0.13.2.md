# إصدار 0.13.2 — مدة حفظ البلاغات

تُزال رسائل البلاغات والاقتراحات من قناة المراجعة الخاصة بعد مرور ٩٠ يومًا، بفحص دوري كل ساعة يبدأ بعد اتصال البوت. يشمل الحذف الرسائل القديمة والجديدة والمثبتة التي أرسلها رفيق بصيغة المراجعة، دون رسائل المشرفين أو البوتات الأخرى أو الرسائل الأحدث.

الحذف على دفعات محدودة، ويستأنف بعد انقطاع الاتصال أو إعادة التشغيل. فشل الحذف لا يتجاوز الرسالة المتعذرة. لا تُنشأ قاعدة جديدة أو نسخة من نص البلاغ؛ الصلاحية المطلوبة هي قراءة سجل قناة المراجعة، ولا يحتاج البوت «إدارة الرسائل».

تعرض صفحة البلاغ والنموذج مدة الاحتفاظ قبل الإرسال. يتوفر رابط سياسة الخصوصية من صفحة المساعدة والاقتراح. تشرح السياسة الحذف المبكر برقم الملاحظة وحدود الحذف داخل Discord وحقوق المستخدم، مع بقاء الإرسال بهوية الحساب كما في الإصدار السابق.

تعرّف السياسة العامة المسؤول عن معالجة البيانات وتوضح غرض المراجعة الخاصة وأساسها وحقوق المستخدم. تُستقبل طلبات الخصوصية عبر نموذج البلاغ الحالي. يظهر رابط السياسة داخل البوت؛ لا تتضمن واجهة البوت اسم المشغّل أو رابط حسابه الشخصي.

لا تغيير في قاعدة تفضيلات المستخدمين أو الاشتراكات أو النصوص الدينية. لا يحتاج هذا الإصدار إلى ترحيل بيانات أو تعديل صلاحيات السيرفرات؛ تبقى إعدادات قناة المراجعة الخاصة الموجودة كما هي.
