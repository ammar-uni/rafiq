# إصدار 0.13.1 — البلاغ والاقتراح

يتوفر «اقتراح» في الرئيسية والمساعدة، ونموذج بلاغ من صفحات مصادر المحتوى. يرفق البلاغ المادة ومصدرها، ويصل إلى قناة مراجعة خاصة بعد إرسال المستخدم فقط. يوضح التحديث قبل الإرسال أن الملاحظة ليست مجهولة المرسل: يُرفق اسم حساب ديسكورد ومعرّفه للمراجعة والحد من السبام، دون المدينة أو التفضيلات. يُعطى رقم ملاحظة بعد نجاح الإرسال، ولا تُعدّل النصوص تلقائيًا. البلاغات القديمة لا تتغير.

أُزيل زر التواصل المباشر مع المشغّل. تتم المتابعة وطلبات حذف الملاحظة من نموذج البلاغ باستخدام رقمها. تبقى حدود الإرسال ثلاث محاولات للحساب خلال ٢٤ ساعة، بفاصل عشر دقائق، و٣٠ محاولة إجمالية في الساعة.

تظل قاعدة التخزين بالإصدار ٨؛ لا تغيير في إعدادات الأعضاء أو المنشورات أو الجدولة أو المواد الدينية المعتمدة. النماذج وأوقات محاولاتها في الذاكرة فقط؛ نصوص الملاحظات في قناة ديسكورد الخاصة.

قبل التشغيل، أنشئ القناة الخاصة واضبط معرّفيها في ملف البيئة وفق [دليل البلاغ والاقتراح](feedback.md). يتحقق البوت من خصوصيتها قبل كل إرسال؛ إن لم تُضبط الوجهة، يوضح تعذر النماذج ولا يفتحها. لا تحتاج دعوة جديدة أو صلاحيات إضافية عامة للبوت. النماذج المفتوحة قبل إعادة التشغيل تنتهي صلاحيتها، ويجب فتح نموذج جديد لقراءة التنبيه قبل الإرسال.

التحقق: ١٩١ اختبارًا للبوت، و٥٥٠ قالب رسائل، و٦ اختبارات لخدمة التحديث. تشمل الاختبارات مصدر هوية الحساب ووضوح التنبيه قبل الإرسال، وملكية النموذج وانتهاء صلاحيته ومنع التكرار والإرسال المتزامن وحدود الطلبات وخصوصية الوجهة وتعذر تأكيد الوصول وتحويل النماذج إلى صيغة ديسكورد الأصلية، مع مطابقة بيانات المستخدمين قبل الإرسال وبعده. جُرّبت النماذج والأزرار والعودة في المعاينة المحلية دون إرسال أي ملاحظة حقيقية.
