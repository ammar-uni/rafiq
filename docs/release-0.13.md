# إصدار 0.13.0 — البلاغ والاقتراح

أضيف «اقتراح» إلى الرئيسية والمساعدة، ونموذج بلاغ من صفحات مصادر المحتوى. يرفق البلاغ المادة ومصدرها، ويصل إلى قناة مراجعة خاصة بعد إرسال المستخدم فقط. لا نرفق اسم حسابه أو معرّفه أو مدينته تلقائيًا. يُعطى رقم ملاحظة بعد نجاح الإرسال، ولا تُعدّل النصوص تلقائيًا.

تظل قاعدة التخزين بالإصدار ٨؛ لا تغيير في إعدادات الأعضاء أو المنشورات أو الجدولة أو المواد الدينية المعتمدة. النماذج وأوقات محاولاتها في الذاكرة فقط؛ نصوص الملاحظات في قناة ديسكورد الخاصة.

قبل التشغيل، أنشئ القناة الخاصة واضبط معرّفيها في ملف البيئة وفق [دليل البلاغ والاقتراح](feedback.md). يتحقق البوت من خصوصيتها قبل كل إرسال؛ إن لم تُضبط الوجهة، يبقى رابط الدعم متاحًا ولا تفتح النماذج. لا تحتاج دعوة جديدة أو صلاحيات إضافية عامة للبوت.

التحقق: ١٩٠ اختبارًا للبوت، و٥٥٠ قالب رسائل، و٦ اختبارات لخدمة التحديث. تشمل الاختبارات ملكية النموذج وانتهاء صلاحيته ومنع التكرار والإرسال المتزامن وحدود الطلبات وخصوصية الوجهة وتعذر تأكيد الوصول وتحويل النماذج إلى صيغة ديسكورد الأصلية، مع مطابقة بيانات المستخدمين قبل الإرسال وبعده. جُرّبت النماذج والأزرار والعودة في المعاينة المحلية دون إرسال أي ملاحظة حقيقية.
