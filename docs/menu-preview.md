# معاينة القوائم الجديدة

معاينة محلية للإصدار `0.11.0`. أضافت مواسم الخير مخطط البيانات v7؛ تتطلب الترقية من v6 إجراء المشغّل في [دليل الإصدار](release-0.11.md).

## تجربة المستخدم

- **الرئيسية:** بداية واضحة لاختيار المدينة، ثم ثلاثة مسارات: تذكيراتي، أقرأ الآن، وأفكار الخير. المؤقّت والمحفوظات والمساعدة في أسفل البطاقة.
- **تذكيراتي:** حالة كل مجموعة وزر واحد لفتحها. إعداد كفارة المجلس يحمل اسمه بدل عنوان «إعداداتك» العام.
- **أذكار الصباح والمساء:** اختيار الفترة أولًا، ثم صفحة واحدة للحالة والموعد والتفعيل والقراءة. يعود تعديل الموعد إلى الفترة نفسها.
- **قراءة القرآن:** صفحة مستقلة. يبقى التفعيل غير متاح حتى حفظ المدينة والساعة، مع توضيح المطلوب.
- **أقرأ الآن:** قراءة الأذكار والمكتبة دون تفعيل اشتراك.
- **رجوع:** زر موحّد في أسفل القوائم الفرعية يفتح القائمة الأم دون تغيير الاختيارات. زر «الرئيسية» يختصر العودة للبداية من الصفحات الأعمق. الرجوع من مصادر الأذكار يعيد فترة الصباح أو المساء نفسها، وتبقى خطوات الإعداد داخل مسارها.
- **الإعداد الأول:** اختيار المدينة مباشرة، مراجعة مواقيتها، اختيار التذكيرات، ثم تجربة إشعار اختيارية. أزرار متابعة واضحة دون تكرار روابط الرئيسية داخل الخطوات.
- **التفعيل مع المدينة:** يوضّح البحث قبل الحفظ أن اختيار المدينة لأول مرة يفعّل دعاء الجمعة وقضاء قبل رمضان في الخاص، عند توفر مواقيت مكتملة. لا يفعّل البحث وحده شيئًا. يمكن إيقاف كل تذكير مستقلًا، وتغيير المدينة لاحقًا يحافظ على هذه الاختيارات ويحدّث توقيت التذكيرات المفعّلة.
- **الصلاة والجمعة:** زر «تفعيل الصلاة والجمعة» يفعّل الصلوات الخمس وتذكير صلاة الجمعة قبل الظهر بـ٤٥ دقيقة. يمكن إيقاف الجمعة وحدها؛ الضغط المكرر لا يلغي إيقافها. الأزرار القديمة التي وعدت بالصلوات الخمس فقط تبقي سلوكها السابق.

## التجربة المحلية

شغّل `npm run preview`. المعاينة تستخدم منطق القوائم الفعلي مع مخزن مؤقت، دون اتصال بديسكورد أو إرسال رسائل. البحث عن المدن فعلي؛ يُستخدم Open-Meteo عند الحاجة، ويظهر التنبيه قبل البحث. تتوفر معاينة بعرض الجوال ومظهر فاتح وداكن.

راجع المسار التالي: الرئيسية ← ابدأ الإعداد ← اختر مدينتي ← مكة المكرمة، السعودية ← اختيار المدينة ← متابعة الإعداد ← اختيار الأذكار ← ضبط الصباح ← تعديل الموعد ← الحفظ ← التفعيل. تحقق أن المساء بقي كما هو، ثم جرّب القراءة والرجوع.

## نطاق التغيير

أبقى تحديث القوائم وحده الأذكار والأحاديث ومصادرها ومواعيدها ومخطط v6 كما هي؛ إضافة مواسم الخير اللاحقة موضّحة أدناه وتستخدم v7. لا تُفعّل التذكيرات من التصفح أو البحث أو حفظ موعد الأذكار والقراءة. وُضّحت خيارات التفعيل الجديدة في الخصوصية ودليل الاستخدام؛ لم تتغير صلاحيات البوت. لا تفعيل جماعيًا للمستخدمين السابقين؛ تبقى اختياراتهم كما هي. تجربة الهاتف الفعلية للإشعار تحتاج ديسكورد؛ المعاينة لا تثبت وصول إشعار دفع.

## مواسم الخير

- مفعّلة تلقائيًا عند «ابدأ مع رفيق»، دون مدينة أو زر تفعيل موسمي منفصل. يظهر هذا بوضوح منذ البداية، وتُحفظ رغبة من أوقفها حتى قبل البدء.
- تذكيران فقط في المحتوى الأولي: واحد للعشر وواحد لعرفة، كل منهما قبل موعده السعودي المتوقع بيومين. لا إرسال ثانٍ قبل يوم.
- حديث مختصر ومصدره، والتاريخ بصيغة متوقعة حتى مراجعة الإعلان. النص العادي قابل للظهور في معاينة إشعار الجوال.
- زر «شاهد نموذج رسالة» للمراجعة الخاصة، و«نموذج آخر» لعرض النموذج الثاني دون إرسال أو اشتراك. التفاصيل خلف المصدر.
- تخزين v7 مع ترحيل يحفظ التفضيلات السابقة. [دليل الإضافة ومتطلبات النشر](seasonal-reminders.md).
