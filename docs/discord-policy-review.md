# مراجعة سياسات ديسكورد

تاريخ المراجعة: ٨ سبتمبر ٢٠٢٦. هذه مراجعة للتنفيذ ومتطلبات التشغيل، وليست اعتمادًا صادرًا من ديسكورد.

## النتيجة

رفيق معين اختياري على الذكر وعمل الخير وتنظيم الوقت؛ كفارة المجلس إحدى ميزاته. لم نجد في المحتوى الحالي أو آلية التذكير غرضًا محظورًا في السياسات التي راجعناها. الإطلاق يتطلب إكمال بيانات الخصوصية والدعم، وحماية بيئة التشغيل، ثم التجربة الفعلية.

## المتطلبات وما يقابلها في التطبيق

| المتطلب | التنفيذ والتحقق |
| --- | --- |
| إذن واضح قبل مراسلة العضو، واحترام الإلغاء والحظر | تفعيل صريح لكل سيرفر، مؤقّت واختبار خاص بطلب العضو؛ التعطيل والحذف يمنعان الإرسال المنتظر؛ فشل الوصول يعلّق المحاولات |
| منع الرسائل المزعجة والتحايل على حدود API | حد متحرك مشترك بين السيرفرات؛ حجز المحاولة قبل الشبكة؛ لا إعادة تلقائية للفشل المبهم ولا بديل في القناة العامة |
| استخدام البيانات لغرض الميزة فقط | معرّفات وتفضيلات وظيفية؛ لا تصنيف ديني للأعضاء أو علاقاتهم، ولا جمع أعمار أو إعلانات أو تدريب نماذج على محادثاتهم |
| إتاحة الإبلاغ ومتابعته | قسم «مساعدة وإبلاغ» يصل إلى وسيلة تواصل المشغّل؛ يلزم رابط دعم فعلي ومراجعة المشغّل للبلاغات |
| سياسة خصوصية متاحة ورابط في البوابة والبوت | أُعدّت مسودة؛ يتوقف بدء الاتصال إذا لم يُضبط رابط الخصوصية والدعم |
| تشفير البيانات المحفوظة | لقطة AES-256-GCM، بمفتاح منفصل؛ SQLite في الذاكرة فقط؛ اختبار رفض المفتاح الخاطئ والعبث وفشل الحفظ |
| حذف البيانات غير اللازمة أو المطلوبة للحذف | زر حذف، تنظيف محاولات أقدم من ٤٨ ساعة، وإزالة اشتراكات السيرفرات التي حذفت البوت حتى أثناء توقفه |
| حساب بوت رسمي وصلاحيات مناسبة | Bot + applications.commands، دون حساب مستخدم آلي أو Administrator أو صلاحية دخول الصوت أو privileged intents |

المصدر: [سياسة المطوّرين](https://support-dev.discord.com/hc/en-us/articles/8563934450327-Discord-Developer-Policy)، و[شروط المطوّرين، خاصة القسم ٥](https://support-dev.discord.com/hc/en-us/articles/8562894815383-Discord-Developer-Terms-of-Service).

## قبل تشغيل الحساب الحقيقي

1. أكمل مساحة الدعم التي يستطيع مستخدمو رفيق الوصول إليها، وانشر سياسة الخصوصية بمعلومات المشغّل والتواصل الصحيحة. ضع الرابط في Developer Portal وفي `RAFIQ_PRIVACY_URL`، ورابط الدعم في `RAFIQ_SUPPORT_URL`. التحقق البرمجي من صيغة الرابط لا يثبت محتواه أو إتاحته؛ افحصهما دون تسجيل دخول قبل الإطلاق.
2. احفظ الرمز ومفتاح التشفير خارج Git، واقصر الوصول إلى `.env` والجهاز على المشغّل المصرّح له. احفظ مفتاح الاستعادة منفصلًا عن نسخ البيانات. تحقّق من تشفير قرص المضيف ونسخه الاحتياطية؛ لم نستطع إثبات حالة BitLocker لهذا الجهاز بصلاحيات الجلسة الحالية.
3. لا توجّه الخدمة لمن هم دون الحد الأدنى لاستخدام ديسكورد: ١٣ سنة على الأقل، وقد يكون أعلى بحسب البلد. لا نضيف جمع تواريخ الميلاد أو وثائق الهوية إلى البوت. راجع [متطلبات العمر](https://discord.com/terms#2).
4. تابع بلاغات المستخدمين، وتعامل مع طلبات التصحيح والحذف. عند حادث وصول غير مصرح به، أوقف التعرض وأبلغ ديسكورد والمتأثرين وفق التزامك. عند إنهاء تشغيل المشروع، احذف بيانات API غير الواجب الاحتفاظ بها.
5. اختبر الإذن والإلغاء والحذف والخاص المغلق في سيرفر تجربة قبل التوسع. استمرار الامتثال يعتمد أيضًا على كيفية إدارة البوت والمحتوى والدعم؛ راجع [إرشادات المجتمع](https://discord.com/guidelines) عند إضافة ميزات أو محتوى جديد.

## حدود النسخة

التخزين المشفّر مناسب لعملية واحدة وسيرفرات قليلة، ويعيد كتابة لقطة عند تغيير البيانات. يرفض ملفات SQLite القديمة بدل تحويلها أو حذفها تلقائيًا. لم توجد بيانات تشغيل حقيقية وقت هذا التحديث؛ أي تثبيت أقدم يحوي بيانات يحتاج ترحيلًا منفصلًا قبل تشغيله.

لا توجد نسخ احتياطية آلية أو تحليلات لأعضاء السيرفر. إذا أنشأ المشغّل نسخًا يدوية، فعليه حمايتها وإزالة البيانات المطلوب حذفها منها أيضًا؛ لا تستعد نسخة تعيد اشتراكات أو بيانات سبق حذفها.
