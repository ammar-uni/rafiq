# رفيق 0.6 — محفوظاتك واختياراتك

## ما الجديد؟

- صفحة «محفوظاتي» للأذكار والأفكار، مع حفظ الأفكار وإزالتها وتصفحها والعودة من مصدرها إلى المكان نفسه.
- إلغاء تذكير المجلس في سيرفر واحد من الإعدادات، مع إبقاء المؤقّت ومحفوظات العضو وسيرفراته الأخرى.
- تمديد مؤقّت الاستراحة ١٥ دقيقة، بحد أقصى ساعتين من وقت الطلب. يُستبدل الموعد السابق ولا تُرسل رسالتان. في رسالة الاستراحة زر لطلب مؤقّت جديد؛ لا تكرار تلقائي.
- توضيح صمت المؤقّت وحالة الخاص والإيقاف المؤقت، وإظهار نهاية الإيقاف.
- غلاف حديقة الفجر مع الهوية نفسها وتصحيح تشكيل «خيرٌ يرافقك». عنوان الزر الرئيسي «مساحتي مع رفيق».
- المعاينة المحلية تستخدم منطق التفاعل نفسه في `src/app.mjs`، مع مخزن تجريبي في الذاكرة وبدون اتصال بديسكورد. تتضمن المظهرين الفاتح والداكن وتخطيطًا يتكيف مع الهاتف.

## البيانات والمحتوى

أفكار الخير المحفوظة علامات مرجعية فقط، ولا نسجّل تنفيذها. تستخدم جدول المحفوظات الموجود بمعرّفات تبدأ بـ `idea:`، دون تغيير صيغة الملف المشفّر. تُحفظ تفضيلات 0.5 وتبقى قابلة للقراءة. حذف بيانات العضو يحذف النوعين من المحفوظات. سياسة الخصوصية محدثة لهذه الإضافة.

لم تُعدّل النصوص الدينية ولا الأسانيد ولا المراجع ولا سجل مراجعتها في هذا الإصدار. الفحوص تؤكد تطابقها مع السجل السابق، ولا تدّعي إجراء تصحيح شرعي آلي.

## قبل التشغيل الفعلي

هذا تحديث للكود والأصول. لا يشغّل خادمًا جديدًا ولا يحدّث تطبيق ديسكورد المتصل وحده. عند موعد النقل: احتفظ بنسخة من البيانات ومفتاحها، أوقف النسخة السابقة، ثبّت التحديث وشغّل عملية واحدة. عند الرغبة بتحديث بطاقة سيرفر قائمة، يعيد المشرف `/rafiq-setup` في القناة نفسها. لم تتغير الأوامر أو الصلاحيات.

## التجربة

نجحت محليًا ٦٠ حالة اختبار و٩٩ صيغة لرسائل ديسكورد، مع محاكاة للمجلس والمؤقّت والحذف. شملت الفحوص بقاء المحفوظات بعد إعادة فتح التخزين، والتراجع عند فشل الكتابة، وعزل المستخدمين والسيرفرات، وتطابق رحلات المعاينة مع منطق البوت. روجع العرض بصريًا بعرض ٣٦٠ و٧٣٦ بكسل. لم يُجرَ اختبار حي على ديسكورد أو خادم الاستضافة ضمن هذا التحديث.

حُدّث ملف Docker وقائمة ملفات البناء واختبار الحاوية لتضمين الغلاف الجديد ومحفوظات الأفكار. لم يُشغّل اختبار الحاوية محليًا لعدم توفر Docker؛ يبقى ضمن فحص GitHub Actions عند رفع التحديث.

```sh
npm run check
npm run demo
npm run preview
```

في المعاينة: احفظ فكرة، افتح «محفوظاتي»، ارجع إلى دليلها، ثم أزلها. اضبط مؤقّتًا ومدّده وألغِه، وجرّب التفعيل والإلغاء في الإعدادات. تبدأ المعاينة من جديد عند إعادة تحميل الصفحة.
