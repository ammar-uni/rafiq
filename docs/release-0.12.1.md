# رفيق 0.12.1 — عشرون منشورًا معتمدًا

تضيف هذه النسخة المنشورات ١١–٢٠ إلى دورة المنشورات العامة بعد اعتماد صاحب المشروع نصوصها ومصادرها بتاريخ ٢٩ سبتمبر ٢٠٢٦. أصبح المجموع عشرين منشورًا من الصحيحين، ولكل منشور زر «المصدر والتوضيح». [النصوص وسجل المراجعة](reminder-posts.md).

تبقى إعدادات الأعضاء والسيرفرات، والمواعيد، والعدد اليومي، والمنشن، ومواسم الخير كما اختارها المستخدمون. يتوسع المحتوى المتناوب فقط؛ لا تُرسل الترقية رسائل فورية ولا تُفعّل النشر لسيرفر أوقفه. قد يتغير المنشور التالي لأن دورة الاختيار توسعت.

## التحقق

- نجح ١٧٨ اختبار JavaScript وفحص ٥٢٨ صيغة لرسائل Discord.
- طابقت النصوص العشرون ملف المراجعة حرفيًا، مع تفاصيل المصدر والراوي وحدود النقل.
- اختُبرت دورة من عشرين يومًا، تعبر نهاية الشهر، لكل اختيار من تذكير واحد أو اثنين أو ثلاثة؛ لا يتكرر منشور داخل اليوم نفسه.
- بقيت بصمات المواد التسع والعشرين السابقة دون تغيير. أُضيفت عشر بصمات للمحتوى الجديد فقط.
- أُعيد بناء المعاينة وتصدير ٦٢ مثالًا للرسائل. تشمل اختبارات الإصدار حفظ الإعدادات واستقلال المنشورات العامة عن التذكيرات الشخصية.

## التحديث

يبقى مخطط البيانات ٨ دون ترحيل. يستخدم الخادم محدّث الإصدار 0.12: يتحقق من نجاح فحص GitHub للنسخة نفسها، ويبنيها ويختبرها بحساب محدود، ثم يعيد تشغيل الخدمة ويتحقق من الجاهزية. يمكن الرجوع إلى 0.12.0 دون تغيير مخطط التخزين. [دليل منشورات السيرفر](server-posts.md).
