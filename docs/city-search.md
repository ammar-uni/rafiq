# البحث عن المدن — 0.8.1

اكتب اسم مدينتك، مثل **بريدة، السعودية** أو **مكة المكرمة، السعودية**، ثم اختر النتيجة التي تطابق بلدك. يمكن البحث بالعربية أو بالأسماء المحلية والإنجليزية. لا يختار البوت مدينة تلقائيًا، ولا يستنتج موقعك من حسابك أو اتصالك.

المعاينة المحلية تستخدم البحث الحقيقي نفسه عبر `/api/cities`؛ أُزيلت قائمة برلين ومكة ونيويورك الثابتة. تشغيلها بـ `npm run preview`، ثم فتح عنوانها المحلي. البحث لا يعمل من ملف HTML منفصل دون خادم المعاينة. تظهر حالة انتظار ورسالة مفيدة عند فشل البحث، ويظل اختيار المدينة السابق محفوظًا في البوت.

## المصدر والتغطية

- الفهرس المرفق مشتق من **GeoNames**، بترخيص [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). المصدر: [cities500.zip](https://download.geonames.org/export/dump/cities500.zip) و[أسماء المناطق الإدارية](https://download.geonames.org/export/dump/admin1CodesASCII.txt)، وفق [شرح الحقول](https://download.geonames.org/export/dump/readme.txt).
- لقطة **2026-09-13**: **35,969** سجل مدينة أو بلدة لها أسماء بالخط العربي، مع الاحتفاظ بأسمائها البديلة بلغات أخرى. تشمل مثلًا بريدة وعنيزة والمدينة المنورة والخرطوم وطوكيو ولندن. لا تعني هذه الأرقام أن كل مدينة في العالم موجودة في الفهرس المحلي.
- التعديلات على المصدر: اختيار الأماكن المأهولة ذات أسماء بالخط العربي؛ استبعاد الأحياء والأماكن المهجورة والتاريخية؛ حذف الأسماء الأطول من حد البحث؛ تقريب الإحداثيات إلى ثلاثة منازل عشرية. تُحتفظ بمعرّفات المصدر والمناطق الزمنية. يعالج التطابق التشكيل والتطويل وبعض بدائل الحروف وأداة التعريف العربية، دون اختراع إحداثيات.
- البلد المكتوب يقيّد النتائج، وتُرتب التطابقات المحلية بحسب كونها مقار إدارية ثم عدد السكان. تتضح الدولة دائمًا، وتُميّز الأسماء المتطابقة بالمناطق أو إحداثيات المركز عند الحاجة. اختيار المستخدم مطلوب؛ الترتيب ليس إثباتًا لموقعه.
- عند عدم وجود تطابق محلي مناسب، يستمر البحث العالمي بواسطة [Open-Meteo / GeoNames](https://open-meteo.com/en/docs/geocoding-api)، مع التحقق من صلاحية المدينة والمنطقة الزمنية. تُحفظ أولوية المزود لنتائج البحث المترجمة. لا تظهر مدن تجريبية عند غياب النتائج. قد تغيب قرية أو تهجئة معينة عن بيانات المزود؛ جرّب الاسم الكامل والدولة أو تهجئة بديلة.
- لا يغير اختيار مكة كمثال طريقة حساب المدن الأخرى: تستخدم كل مدينة إحداثياتها ومنطقتها الزمنية، مع إعدادات الحساب الحالية.

## تحديث الفهرس

نزّل الملفين من الروابط الرسمية أعلاه إلى مجلد عمل مؤقت، ثم شغّل:

```sh
python scripts/build-city-index.py /path/to/cities500.zip /path/to/admin1CodesASCII.txt
npm run check
npm run preview:build
```

راجع التغييرات في `src/data/city-aliases.json`، بما فيها تاريخ اللقطة وبصمتا SHA-256، وأعد اختبار أسماء المدن المطلوبة قبل نشر التحديث. عملية البناء تقرأ ملفات البيانات المحلية فقط، ولا تحتاج حسابًا أو مفتاح خدمة. الفهرس جزء من إصدار البوت، فلا توجد عملية تنزيل دورية أو اشتراك جديد.

تظل بيانات المستخدم على المخطط **v4**؛ لا تحتاج الترقية من 0.8.0 إلى 0.8.1 إلى تحويل البيانات أو إعادة تسجيل أوامر ديسكورد. أُبقيت الاشتراكات والمواقيت والمصادر الدينية كما هي. يرجى مراجعة [سياسة الخصوصية](privacy-policy.md) و[شروط البحث الخارجي](prayer-reminders.md).
