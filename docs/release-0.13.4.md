# رفيق — الإصدار 0.13.4

أُضيفت عشرون رسالة من صحيح البخاري وصحيح مسلم، بأرقام ثابتة ٤١–٦٠، ليصبح مجموع المنشورات العامة ستين. نُقلت الأحاديث الجديدة كاملة دون الإسناد أو حذف جمل للاختصار، مع إبقاء سياق الحوار وقيود الرواية وفصل كلام الرواة عن القول النبوي. طوبقت ألفاظها مع الروايات العربية المحفوظة في اختبار مستقل، ويعرض زر «المصدر والتوضيح» الراوي والعزو وحدود النقل. [ملف مراجعة الدفعة](reminder-posts-41-60.md).

صُحح التناوب حتى تمر كل ساعة نشر محفوظة على جميع المنشورات الستين قبل التكرار، وتبقى منشورات اليوم الواحد مختلفة. أُضيف فحص يمنع علامات الاقتباس غير المغلقة أو المرتبة خطأ، بما فيها الاقتباسات المتداخلة، في النصوص والمصادر وملفات المراجعة.

لا تتغير النصوص الأربعون السابقة أو بقية الأذكار والمواسم أو إعدادات الأعضاء والسيرفرات. لا زيادة في العدد اليومي، ولا تفعيل تلقائي لسيرفر متوقف، ولا تغيير للمنشن أو مخطط التخزين ٨. تدخل الإضافة في المواعيد المحفوظة بعد تثبيت الإصدار؛ لا يُرسل التحديث رسائل تجريبية أو تعويضية.

الفحوص المطلوبة قبل النشر: `npm ci --ignore-scripts`، ثم `npm run check` و`npm run demo` وتصدير أمثلة الرسائل وبناء المعاينة. تشمل الاختبارات مطابقة الستين رسالة، وكامل ألفاظ الدفعة الجديدة، وتغطية التناوب عبر الأشهر والسنوات، وحفظ التفضيلات وسجل منع التكرار. تتبعها فحوص Linux والحاوية في GitHub، ثم التحقق من اتصال Gateway ونبض العامل على الخادم. الفحوص البرمجية تتحقق من النقل والتغيير، ولا تصحّح الأسانيد.

يتبع التثبيت والرجوع الآلية القائمة في [دليل VPS](vps-deployment.md). تبقى الأسرار والبيانات المشفرة خارج النسخ البرمجية، ولا يحتاج هذا الإصدار إلى ترحيل بيانات أو تغيير وحدات النظام.
